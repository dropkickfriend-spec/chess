Architecture

chess-bb is a bitboard-based UCI chess engine with a self-tuning evaluation function. Key features:

  • Strategy-Based Evaluation: 11 independent evaluation strategies covering opening, middlegame, and endgame phases
  • Self-Learning: After each game, strategy weights adjust based on outcome (1.02× for wins, 0.98× for losses)
  • Tapered Scoring: Midgame/endgame blend based on remaining material (smooth king transition)
  • Alpha-Beta Search: Transposition table, null-move pruning, late-move reduction, history heuristic
  • Weight Persistence: Learned weights saved to disk and loaded on engine startup

Live dashboard for chess-bb self-play experiments. Data updates automatically from game results and weight files.
