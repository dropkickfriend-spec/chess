Architecture

chess-bb is a bitboard-based UCI chess engine with a self-tuning evaluation function.

  • Strategy-Based Evaluation: 11 strategies competing for a fixed per-move evaluation budget (relative reweighting — only ratios matter)
  • Self-Learning: surprise-driven, zero-sum weight updates after each game; square/piece values relearned from the permanent game log via Texel tuning
  • Mate dominance: eval clamped so no learned bonus outranks a search mate score; material discounts itself under king danger
  • Search: alpha-beta with transposition table, null-move pruning, LMR, history heuristic
  • Persistence: weights stored locally and in Supabase; the chart pulls the full learning history live
